# 現代文キーワード辞典

大学入試の現代文（評論）に出るキーワード **285語** を、8分野から引ける学習用の1ページアプリです。
ビルド不要・依存ライブラリなし。`index.html` を開くだけで動きます。

## 収録分野

| 分野 | 分野コード | 語数 |
| --- | --- | ---: |
| 言語とコミュニケーション | `gengo` | 33 |
| 科学と人間 | `kagaku` | 33 |
| 近代・国際・異文化 | `kindai` | 48 |
| 日本と伝統文化 | `nihon` | 27 |
| 芸術 | `geijutsu` | 22 |
| 文学表現 | `bungaku` | 29 |
| 論理・思考 | `ronri` | 43 |
| 頻出漢字語 | `kanji` | 50 |

各語に「読み・語義・用例・関連語（対義／類義）」を収めています。

## 4つのモード

- **辞典** — 検索と、分野・習得状況による絞り込み。語ごとに「まだ／あいまい／覚えた」を仕分け
- **暗記カード** — 絞り込んだ範囲をシャッフルして1枚ずつ。めくって仕分け
- **四択テスト** — 10問。語→意味と意味→語を交互に出題し、誤答選択肢は同じ分野から選ぶ
- **進捗** — 分野別の習得率、復習の予定、取りこぼした語を集めた重点復習リスト

タブのすぐ下に「今日の復習」の帯が出ます。その日に解き直す語の数と、そこへ直行する
ボタンだけを置いてあり、何から手をつけるか迷わずに済むようにしてあります。

はじめて開いた人には使い方が自動で表示され、一度閉じれば以降は出ません。
見出し右上の「使い方」からいつでも読み返せます。

ダークモード対応（OSの設定に追従。右上のボタンで手動切替も可）。

## 復習の間隔

語ごとに「復習箱」（0〜5）を持たせ、次に出題する日を決めています。

| 箱 | 0 | 1 | 2 | 3 | 4 | 5 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| 次に出すまで | 当日 | 1日 | 2日 | 4日 | 7日 | 14日 |

**覚えた**と四択の正解で箱が一つ上がり、**まだ**と誤答は箱0に戻ります。**あいまい**は箱1
（翌日）。誤答しても「覚えた」から一気に「まだ」へは落とさず、一段だけ下げます。

絞り込みの**要復習**は期限が来た語、**苦手**は「まだ」の語と誤答が正答を上回る語です。
この絞り込みは暗記カードと四択テストにもそのまま効くので、弱いところだけを繰り返せます。

四択テストの10問は二段階で選びます。

1. **期限の来た語を、期限の古い順に確保する。** ここはシャッフルしません。混ぜると、
   期限の来た語が1語しかないときに入らないことがあるためです。
2. 残りを、まだ出していない語 → 苦手 → それ以外の順に並べ、最後に出題してから間の
   空いた順で上位（必要数の2倍）を取り、シャッフルして埋める。

直前に出た語が続けて出ることはなく、それでいて毎回同じ組にもなりません。1〜4のキーでも
解答できます。

なお、**誤答した語が必ず次の10問に出るとは限りません**。誤答した語の期限は当日になりますが、
それより古い期限の語が溜まっていれば、そちらが先に出ます。溜まりが解消しだい戻ってきます。

## 授業で配る

### 範囲をURLで渡す

辞典の絞り込み（分野・習得状況・検索語）を決めてから「この範囲のリンクをコピー」を押すと、
その範囲で開くURLが手に入ります。「今週は言語分野の18語」を口頭で伝える必要がなくなります。

| パラメータ | 値 | 例 |
| --- | --- | --- |
| `c` | 分野コードをカンマ区切り | `?c=gengo,kagaku` |
| `st` | `all` / `due` / `ng` / `0`〜`3` | `?st=ng`（苦手だけ） |
| `q` | 検索語 | `?q=近代` |
| `v` | 開くモード `dict` / `card` / `quiz` / `prog` | `?v=quiz` |

`v` だけはボタンから作られません。四択テストに直行させたいときは、コピーしたURLの末尾に
`&v=quiz` を手で足してください。

### 紙の小テストを書き出す

同じ絞り込みから「この範囲で紙のテストを作る」でA4の確認テストを刷れます。問題数（10/15/20/30）、
出題の向き（語→意味／意味→語／交互）、解答の有無を選べます。**1ページに収めるなら15問まで**が
目安です（実測で、語→意味15問が254mm。A4の刷り込み範囲は265mm）。配布用は「解答なし」で。

### オフライン

`manifest.webmanifest` と `sw.js` を置いてあり、一度開けば回線が無くても使えます。
スマートフォンではホーム画面に追加できます。**Claude Artifact 版には manifest を渡していない**ため、
そちらでは Service Worker を登録しません（`tools/make-artifact.py` は `<title>` 以降を切り出すので、
`<link rel="manifest">` は `<title>` より前に置いてあります）。

アイコン `icon-180/192/512.png` は明朝体の「現」。作り直すときは同じ配色（地 `#27466F`、
字 `#F2F2EE`、下辺の罫 `#B0442C`）で。

## 使い方

`index.html` をブラウザで開くだけです。GitHub Pages で公開すれば、URLを配るだけで使えます。
公開先は <https://upopotennis-gif.github.io/gendaibun-keyword/>。

学習状況は閲覧している端末のブラウザ（`localStorage`、キーは `gendaibun-kw-v3`）にのみ
保存されます。サーバには何も送信しません。

端末をまたぐときは、**進捗**タブ下部の「学習状況の持ち出し」から書き出します。JSONファイル
への書き出しと、文字列のコピーの両方を用意してあります（スマートフォンではファイルの
やり取りが面倒なため、貼り付けでも移せるようにしてあります）。読み込むと、その端末の
学習状況は置き換わります。

1語ぶんの記録は次の形です。

```js
{lv:仕分け(0-3), ok:正答数, ng:誤答数, box:復習箱(0-5), due:次回の日, t:最後に出題した時刻}
```

`due` は端末の時計での日付を通し番号にしたもので、日付をまたいだかどうかだけを見ています。
旧形式 `gendaibun-kw-v2` の記録があれば、初回に自動で引き継ぎます。

## 語を増やす・直す

すべてのデータは `index.html` 内の `W` 配列にあります。1語1行で、次の6項目です。

```js
["見出し語","よみ","語義","用例","関連語","分野コード"],
```

分野コードは `gengo` / `kagaku` / `kindai` / `nihon` / `geijutsu` / `bungaku` / `ronri` / `kanji` のいずれか。
分野そのものを増やすときは `CATS` 配列と、CSS変数 `--c-<分野コード>`（ライト／ダークの両方）を追加します。

学習状況は見出し語そのものをキーに保存しているため、語を足したり並べ替えたりしても進捗はずれません。
ただし**見出し語の表記を変えると、その語の進捗だけリセットされます**。

### 語義を書くときの決まり

**語義は9〜43字に収めてください。** 四択テストの誤答選択肢は他の語の語義をそのまま使うため、
一語だけ極端に長い（短い）語義があると、意味を考えずに長さで正解を当てられてしまいます。
現在は正解が単独で最長になる率22.7%・最短22.7%（偶然なら25%）で、長さの偏りはありません。

崩れていないかは、次で確かめられます。

```sh
python3 tools/check-words.py
```

## Claude Artifact 版との関係

同じ内容を Claude の Artifact としても公開しています。Artifact はページ本体が
`<!doctype html>…<head></head><body>` のひな形で包まれるため、外側のタグを外した
中身だけを渡す必要があります。

**`index.html` を唯一の正とし、Artifact 版はそこから生成します。**
手で二重に直すとずれるので、下記で切り出してください（`artifact.html` は生成物なので
コミットしません）。

```sh
python3 tools/make-artifact.py
```
