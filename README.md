# 渡邊梢太の現代文キーワード辞典

大学入試の現代文（評論）に出るキーワード **285語** を、8分野から引ける学習用の1ページアプリです。
ビルド不要・依存ライブラリなし。`index.html` を開くだけで動きます。

## 収録分野

| 分野 | 分野コード | 語数 |
| --- | --- | ---: |
| 言語とコミュニケーション | `gengo` | 33 |
| 科学と人間 | `kagaku` | 33 |
| 近代・国際・異文化 | `kindai` | 48 |
| 日本と伝統文化 | `nihon` | 27 |
| 芸術 | `geijutsu` | 22 |
| 文学表現 | `bungaku` | 29 |
| 論理・思考 | `ronri` | 43 |
| 頻出漢字語 | `kanji` | 50 |

各語に「読み・語義・用例・関連語（対義／類義）」を収めています。

## 4つのモード

- **辞典** — 検索と、分野・習得状況による絞り込み。語ごとに「まだ／あいまい／覚えた」を仕分け
- **暗記カード** — 絞り込んだ範囲をシャッフルして1枚ずつ。めくって仕分け
- **四択テスト** — 10問。語→意味と意味→語を交互に出題し、誤答選択肢は同じ分野から選ぶ
- **進捗** — 分野別の習得率、復習の予定、取りこぼした語を集めた重点復習リスト

タブのすぐ下に「今日の復習」の帯が出ます。その日に解き直す語の数と、そこへ直行する
ボタンだけを置いてあり、何から手をつけるか迷わずに済むようにしてあります。

はじめて開いた人には使い方が自動で表示され、一度閉じれば以降は出ません。
見出し右上の「使い方」からいつでも読み返せます。

ダークモード対応（OSの設定に追従。右上のボタンで手動切替も可）。

## 復習の間隔

語ごとに「復習箱」（0〜5）を持たせ、次に出題する日を決めています。

| 箱 | 0 | 1 | 2 | 3 | 4 | 5 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| 次に出すまで | 当日 | 1日 | 2日 | 4日 | 7日 | 14日 |

**覚えた**と四択の正解で箱が一つ上がり、**まだ**と誤答は箱0に戻ります。**あいまい**は箱1
（翌日）。誤答しても「覚えた」から一気に「まだ」へは落とさず、一段だけ下げます。

絞り込みの**要復習**は期限が来た語、**苦手**は「まだ」の語と誤答が正答を上回る語です。
この絞り込みは暗記カードと四択テストにもそのまま効くので、弱いところだけを繰り返せます。

四択テストの10問は二段階で選びます。

1. **期限の来た語を、期限の古い順に確保する。** ここはシャッフルしません。混ぜると、
   期限の来た語が1語しかないときに入らないことがあるためです。
2. 残りを、まだ出していない語 → 苦手 → それ以外の順に並べ、最後に出題してから間の
   空いた順で上位（必要数の2倍）を取り、シャッフルして埋める。

直前に出た語が続けて出ることはなく、それでいて毎回同じ組にもなりません。1〜4のキーでも
解答できます。

なお、**誤答した語が必ず次の10問に出るとは限りません**。誤答した語の期限は当日になりますが、
それより古い期限の語が溜まっていれば、そちらが先に出ます。溜まりが解消しだい戻ってきます。

## 授業で配る

### 範囲をURLで渡す

辞典の絞り込み（分野・習得状況・検索語）を決めてから「この範囲のリンクをコピー」を押すと、
その範囲で開くURLが手に入ります。「今週は言語分野の18語」を口頭で伝える必要がなくなります。

| パラメータ | 値 | 例 |
| --- | --- | --- |
| `c` | 分野コードをカンマ区切り | `?c=gengo,kagaku` |
| `st` | `all` / `due` / `ng` / `0`〜`3` | `?st=ng`（苦手だけ） |
| `q` | 検索語 | `?q=近代` |
| `v` | 開くモード `dict` / `card` / `quiz` / `prog` | `?v=quiz` |

`v` だけはボタンから作られません。四択テストに直行させたいときは、コピーしたURLの末尾に
`&v=quiz` を手で足してください。

### 紙の小テストを書き出す

同じ絞り込みから「この範囲で紙のテストを作る」でA4の確認テストを刷れます。問題数（10/15/20/30）、
出題の向き（語→意味／意味→語／交互）、解答の有無を選べます。**1ページに収めるなら15問まで**が
目安です（実測で、語→意味15問が254mm。A4の刷り込み範囲は265mm）。配布用は「解答なし」で。

### 生徒への案内

`haifu/` に配布物を置いてある。

| ファイル | 中身 |
| --- | --- |
| `案内プリント.html` | A4 1枚の案内。これが唯一の正 |
| `案内プリント.pdf` | 上から生成。`./haifu/build-pdf.sh` で作り直す（コミットしない） |
| `投稿文.md` | Classroom などにそのまま貼る本文（短い版・くわしい版） |
| `qr-site.png` | 公開URLのQR（1024px、誤り訂正レベルM） |

**このリポジトリは GitHub Pages で全体が公開される。** `haifu/` の中身も
`https://.../gendaibun-keyword/haifu/…` で誰でも開ける。学校名・クラス名・氏名を
書き加えるときは、コミットせずに手元のコピーでやること。

案内プリントを直すときの注意:

- **`li` を `display:grid` にしたまま中身を直に置かない。** `<b>` や `<em>` が
  それぞれ別のグリッドセルへ飛び、6mm幅の列で1文字ずつ折り返す。中身は `<div class="st">`
  で包む（サイト本体の使い方ダイアログと同じ）。
- **高さを測るときは `min-height:297mm` を外す。** 付けたままだと常に 267mm
  （＝297−余白30mm）が返り、収まっているかの判定にならない。
- 最後は必ず `./haifu/build-pdf.sh` でページ数を確かめる。現状 252.8mm／余裕16.2mm。

### オフライン

`manifest.webmanifest` と `sw.js` を置いてあり、一度開けば回線が無くても使えます。
スマートフォンではホーム画面に追加できます。**Claude Artifact 版には manifest を渡していない**ため、
そちらでは Service Worker を登録しません（`tools/make-artifact.py` は `<title>` 以降を切り出すので、
`<link rel="manifest">` は `<title>` より前に置いてあります）。

アイコン `icon-180/192/512.png` は明朝体の「現」。作り直すときは同じ配色（地 `#27466F`、
字 `#F2F2EE`、下辺の罫 `#B0442C`）で。

## 学習ガイドと解説動画

分野ごとに「考え方の流れ」を読むページ（`guide/<分野コード>.html`）と、同じ流れを合成音声で
説明する動画（`guide/<分野コード>.mp4`、字幕付き）を置いている。一覧は `guide/index.html`、
サイトの見出しの「学習ガイド」から入れる。**8分野すべて作ってある**（2026-09。近代・国際・異文化を
試作して形を決め、残り7分野を同じ形で作った）。頻出漢字語だけは考え方の流れを持たないので、
「ぶつかる」「行き詰まる」のような意味のまとまりで章を立て、紛らわしい語の対比を中心にしている。

### 原稿がひとつ、出力がふたつ

**ガイドのページと動画は、`guide/src/<分野コード>.md` ひとつから作る。** 別々に書くと、
直したときに片方だけ古くなるため。ページや動画を手で直さないこと。

```sh
python3 tools/guide_src.py guide/src/kindai.md     # 点検（辞典に無い語、どの章にも入っていない語など）
python3 tools/build-video.py guide/src/kindai.md   # 動画と字幕（数分かかる）
python3 tools/build-guide.py kindai                # ページと一覧（動画の後に。長さを字幕から読む）
```

原稿の書き方は `guide/src/kindai.md` の冒頭のコメントにある。要点は2つ。

- `{語}` と書いた辞典の見出し語は、**ページでは辞典へのリンク**（`../?w=語`）に、**ナレーションでは
  辞典の読みがな**に置き換わる。合成音声が「客体」「疎外」などを読み違えないようにするため。
  辞典に無い語を `{}` で囲むと点検で止まる。
- 各章の `words:` に、その章で扱う語を並べる。**分野の語がすべて、ちょうど1つの章に入っている**
  ことを点検する。
- **読みがなに「・」を含む語は、ナレーションで `{}` に入れない。** 読みは「・」の前だけが使われる
  ため、`{侘び・寂び}` は「わび」、`{インフォームド・コンセント}` は「いんふぉーむど」で切れる。
  ナレーションには「わび、さび」のように地の文で書く（ページ側の本文では `{}` のままでよい）。
  `{世論}`（よろん・せろん）は前の読みで正しいので問題ない。
- **人名はナレーションに入れないほうが安全。** 柳宗悦・本居宣長・柄谷行人のような読みは合成音声が
  誤りやすく、しかも辞典に無いので `{}` で読みを渡せない。ページ本文には書き、動画では言い換えた。
- `[title]` `[quote]` `[contrast]` の引数は `|` と**半角の `,`** で区切られる。文中の読点は全角「、」で書く。

### 動画の作り方と、踏んだもの

スライドは HTML をヘッドレス Chrome で 1920×1080 に撮り、音声は macOS の `say`（既定は
**システムの声**・速度165）、組み立ては ffmpeg（`../09 ICT関係/議事録自動化/.bin/ffmpeg` を借用）。
新しい道具は入れていない。中間生成物は `guide/.work/`（コミットしない）に置き、中身が変わらない
スライドや音声は作り直さない。声を変えるときは `--voice` と `--rate`。

**声は Siri の「声2」を使っている。** Kyoko は機械的だという判断で差し替えた。

- Siri の声は `say -v` で名前を指定できない。**設定 → アクセシビリティ → 読み上げコンテンツ →
  システムの声 を Siri ＞ 声2 にしておき**、`--voice system`（既定）で作る。`-r` は効く。
- この Mac の日本語には「プレミアム」「拡張」の Kyoko/Otoya は出てこなかった（macOS 26）。
- システムの声が Kyoko に戻っていると、作り始めに止まる（`system_voice()` が試し読みを
  Kyoko と比べる）。設定を変えた場合は試し読みの指紋が変わるので、音声は自動で作り直される。
- 内蔵の声は規約上「個人的・非営利の利用」が前提。公開の可否はこの前提で判断すること。

- **スライドにウェブフォントを使わない。** `--screenshot` は読み込み完了を待たずに撮ることがあり、
  6枚同時に撮ったら34枚中4枚が文字の無い空白になった。ヒラギノ（システムフォント）にしてある。
  念のため、撮ったあと見出し帯の画素を調べ、空白なら撮り直す。
- **長い語は枠の幅に合わせて文字を縮める**（`fit()`）。固定サイズだと「ヒューマニズ／ム」の
  ように語の途中で折り返した。
- **画面の下の方には何も置かない。** 再生側の字幕が重なる。
- 動画は Service Worker で控えない（部分応答で届き、容量も大きい）。**本文は電波が無くても
  読めるが、動画は通信が必要。**
- 合成音声の読み間違いは機械では確かめられない。原稿を直したら、特に語の読みを耳で確認する。

## 使い方

`index.html` をブラウザで開くだけです。GitHub Pages で公開すれば、URLを配るだけで使えます。
公開先は <https://upopotennis-gif.github.io/gendaibun-keyword/>。

学習状況は閲覧している端末のブラウザ（`localStorage`、キーは `gendaibun-kw-v3`）にのみ
保存されます。サーバには何も送信しません。

端末をまたぐときは、**進捗**タブ下部の「学習状況の持ち出し」から書き出します。JSONファイル
への書き出しと、文字列のコピーの両方を用意してあります（スマートフォンではファイルの
やり取りが面倒なため、貼り付けでも移せるようにしてあります）。読み込むと、その端末の
学習状況は置き換わります。

1語ぶんの記録は次の形です。

```js
{lv:仕分け(0-3), ok:正答数, ng:誤答数, box:復習箱(0-5), due:次回の日, t:最後に出題した時刻}
```

`due` は端末の時計での日付を通し番号にしたもので、日付をまたいだかどうかだけを見ています。
旧形式 `gendaibun-kw-v2` の記録があれば、初回に自動で引き継ぎます。

## 語を増やす・直す

すべてのデータは `index.html` 内の `W` 配列にあります。1語1行で、次の6項目です。

```js
["見出し語","よみ","語義","用例","関連語","分野コード"],
```

分野コードは `gengo` / `kagaku` / `kindai` / `nihon` / `geijutsu` / `bungaku` / `ronri` / `kanji` のいずれか。
分野そのものを増やすときは `CATS` 配列と、CSS変数 `--c-<分野コード>`（ライト／ダークの両方）を追加します。

学習状況は見出し語そのものをキーに保存しているため、語を足したり並べ替えたりしても進捗はずれません。
ただし**見出し語の表記を変えると、その語の進捗だけリセットされます**。

### 語義を書くときの決まり

**語義は9〜43字に収めてください。** 四択テストの誤答選択肢は他の語の語義をそのまま使うため、
一語だけ極端に長い（短い）語義があると、意味を考えずに長さで正解を当てられてしまいます。
現在は正解が単独で最長になる率22.7%・最短22.7%（偶然なら25%）で、長さの偏りはありません。

崩れていないかは、次で確かめられます。

```sh
python3 tools/check-words.py
```

## Claude Artifact 版との関係

同じ内容を Claude の Artifact としても公開しています。Artifact はページ本体が
`<!doctype html>…<head></head><body>` のひな形で包まれるため、外側のタグを外した
中身だけを渡す必要があります。

**`index.html` を唯一の正とし、Artifact 版はそこから生成します。**
手で二重に直すとずれるので、下記で切り出してください（`artifact.html` は生成物なので
コミットしません）。

```sh
python3 tools/make-artifact.py
```
